# Production workflow

1. Choose a category and write a specific visual concept.
2. Generate a complete prompt.
3. Copy it into an image-generation service.
4. Inspect the image at full size for anatomy, geometry, text artifacts, reflections, shadows, and commercial usability.
5. Check file dimensions and format with Image QC.
6. Verify sRGB/ICC profile using a trusted image editor or metadata tool. The browser QC does not inspect it.
7. Draft title and keywords, then manually remove anything not visible in the asset.
8. Check rights, releases, trademarks, and current Adobe Stock generative AI disclosure requirements.
9. Avoid submitting near-duplicate variations.
